# Connecting StructZero via MCP

StructZero operates as a standard Model Context Protocol (MCP) server, bringing multi-model debate into your local IDE.

## Configuration for Cursor / VS Code
Add the following snippet to your `mcpServers` settings JSON:

```json
{
  "mcpServers": {
    "structzero": {
      "command": "npx",
      "args": ["-y", "@structzero/mcp-server"]
    }
  }
}
```
