Welcome to the **StructZero Documentation Portal**.

## Prerequisites
- Node.js v18+ or v20+
- An MCP-compatible client (Cursor, VS Code, Claude Code, Windsurf, Zed)
- Optional: API keys for Gemini, Claude, or DeepSeek (or local Ollama endpoint)

## Installation
Run the following command to connect StructZero via MCP:

```bash
npx @structzero/mcp-server init
```
