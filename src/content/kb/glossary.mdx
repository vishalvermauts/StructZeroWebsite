## Terms & Definitions

- **AST (Abstract Syntax Tree)**: Structural representation of source code syntax used by Project DNA to index codebase contracts.
- **Certification Gate**: The pre-flight verification subsystem that tests syntax, imports, and security rules prior to disk write.
- **Debate Engine**: The multi-model adversarial review subsystem that critiques architecture proposals before code generation.
- **MCP (Model Context Protocol)**: An open standard protocol used to connect StructZero's intelligence engine into external IDEs.
- **Project DNA**: The indexed context graph of exports, routes, interfaces, and file paths extracted from a codebase.
- **Topological Sorting**: Generating dependent code files in strict hierarchical order so base interfaces exist before modules import them.
