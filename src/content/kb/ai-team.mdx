## The 10 AI Team Roles

1. **Strategist**: Classifies requests and defines boundaries.
2. **Architect**: Designs data schemas and system blueprints.
3. **Coder**: Generates code in topological dependency order.
4. **QA & Verifier**: Executes syntax parsing and import checks.
5. **Security**: Audits injection risks and credential leaks.
6. **Data Engineer**: Manages database queries and migrations.
7. **Ops / DevOps**: Manages container and cloud infrastructure.
8. **Designer**: Enforces UI design tokens and layout rules.
9. **Researcher**: Fetches documentation and API references.
10. **Ethicist & Compliance**: Validates data privacy and licensing rules.
