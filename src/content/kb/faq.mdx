## Technical & Architecture Questions

### How does the Multi-Model Debate Engine work?
Before generating code, StructZero assigns independent models (Gemini, Claude, DeepSeek) to opposing roles (Architect, Reviewer, Judge) to critique designs, uncover flaws, and issue an approved patch.

### What is the Certification Gate?
The Certification Gate runs automated AST syntax parsing, import resolution checks, and pre-flight tests. If code fails, an auto-repair loop fixes the issue or restores a clean backup before commit.
