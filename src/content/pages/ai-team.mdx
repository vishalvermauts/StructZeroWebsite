# The AI Engineering Team

StructZero divides complex tasks across **10 specialized roles**:

1. **Strategist**: Analyzes business requirements and scope.
2. **Architect**: Designs data models and system boundaries.
3. **Coder**: Writes modular code in strict topological order.
4. **QA & Verifier**: Tests AST validity and import paths.
5. **Security**: Audits secrets, injection flaws, and permissions.
6. **Data Engineer**: Optimizes schema and queries.
7. **Ops / DevOps**: Configures container and cloud deployment pipelines.
8. **Designer**: Defines UX/UI design tokens and layout rules.
9. **Researcher**: Looks up documentation and API specs.
10. **Ethicist & Compliance**: Checks licensing and data privacy boundaries.
