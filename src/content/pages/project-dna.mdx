# Project DNA Context Engine

Before generating or refactoring code, StructZero parses the project's **Abstract Syntax Tree (AST)** into a structured knowledge graph called **Project DNA**.

## Extracted Assets
- Complete directory & file maps
- Explicit exported symbols & type signatures
- Framework route topologies
- Environment variables & schema contracts

This prevents the AI from inventing non-existent paths or breaking existing module contracts.
